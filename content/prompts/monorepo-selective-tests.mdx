**Context:** Our monorepo is growing. Running all tests on every PR is becoming slow and expensive. We use Turborepo and pnpm.

**Goal:** Configure GitHub Actions to use Turborepo's `--filter` flag to only run tasks (build, lint, test) for affected workspaces based on the git diff between the PR branch and `main`.

**Requirements:**
1. Use `turbo run test --filter=...[origin/main]`.
2. Ensure git depth is sufficient for Turborepo to calculate changes (`fetch-depth: 0`).
3. Handle dependencies correctly (if Package A changes, and Package B depends on A, run tests for both).

**Output:** Provide the optimized GitHub Action YAML.
