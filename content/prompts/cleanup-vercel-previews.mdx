**Context:** My team creates dozens of pull requests a week, leading to a massive accumulation of Vercel preview deployments that we don't need after the PR is merged or closed.

**Goal:** Create a GitHub Action that triggers whenever a Pull Request is closed (either merged or discarded) and uses the Vercel CLI to remove the associated preview deployment to keep our dashboard clean and manage costs.

**Requirements:**
1. Trigger on `pull_request` with `types: [closed]`.
2. Use the Vercel CLI to find deployments for the specific PR branch.
3. Remove those deployments.
4. Handle cases where the deployment might have already been deleted.

**Output:** Provide the GitHub Action YAML and the specific Vercel CLI command to filter by branch name.
