**Context:** I have 15+ environment variables for my Next.js app. Managing them manually in both GitHub Secrets and the Vercel Dashboard is tedious and error-prone.
**Goal:** Write a Bash script or GitHub Action that syncs specific GitHub Secrets to a Vercel project's Preview and Production environments.
**Requirements:**
1. Use the Vercel CLI (`vercel env add` or `vercel env pull/push` logic).
2. The script should read from a `.env.example` file to know which keys to look for in the GitHub Secrets context.
3. Automatically apply these variables to both `Preview` and `Production` environments in Vercel.
**Output:** Provide the Bash script/YAML and instructions on how to safely authenticate the Vercel CLI in GitHub Actions to run this.
