**Context:** We use Railway for its simplicity but want to manage our own Dockerfiles for custom environments.

**Goal:** Create a GitHub Action that builds the Docker image and pushes it to Railway using their CLI.

**Requirements:**
1. Install Railway CLI.
2. Link to a Railway project via a token.
3. Use `railway up` for the deployment.

**Output:** Provide the GitHub Action workflow.
