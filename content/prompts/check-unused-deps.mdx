**Context:** Over time, our `package.json` gets bloated with dependencies we no longer use. This increases build times and the attack surface.

**Goal:** Add a CI step that runs `depcheck` and fails if it finds packages that are installed but not imported anywhere in the code.

**Requirements:**
1. Use `npx depcheck`.
2. Configure ignores for packages that are used but not easily detectable (like `eslint-config-*`).
3. Fail the job if any unused dependencies are found.

**Output:** Provide the GitHub Action step and the `depcheck` configuration.
