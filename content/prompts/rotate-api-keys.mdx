**Context:** Security compliance requires us to rotate our third-party API keys monthly. Doing this manually is a chore and a risk.

**Goal:** Create a scheduled GitHub Action (cron) that calls the third-party provider to generate a new key, then uses the GitHub API and Vercel CLI to update the stored secrets.

**Requirements:**
1. Schedule with `cron: '0 0 1 * *'`.
2. Use a GitHub Personal Access Token (PAT) with `secrets` scope.
3. Include error handling so the old key isn't deleted until the new one is confirmed in both places.

**Output:** Provide the workflow structure and the API calls needed for GitHub/Vercel.
