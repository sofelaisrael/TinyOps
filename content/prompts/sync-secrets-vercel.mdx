**Context:** We have secrets like API keys that need to be available in both GitHub Actions (for testing) and Vercel (for the app). Manually copying them is error-prone.

**Goal:** Build a workflow that uses the Vercel CLI to set or update environment variables on Vercel whenever they are changed in GitHub.

**Requirements:**
1. Use `vercel env add` or `vercel env rm`.
2. Handle different environments (preview vs production).
3. Ensure the Vercel token has the correct permissions.

**Output:** Provide the script to loop through a list of secrets and sync them.
