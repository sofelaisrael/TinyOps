This is caused by a root-level `api/` directory conflicting with Next.js's built-in `pages/api` directory, or by `next-pwa` configuration interfering with routing.

**Goal:** Identify and remove the conflicting root-level `api/` directory, and disable or reconfigure any PWA middleware that intercepts all routes.

2. Show how to check for the conflict: look for both `api/` at root and `pages/api/` in the project.
3. Fix: rename the root-level `api/` directory to something else (e.g., `api_src/` or `backend/`).
4. For `next-pwa`: show how to disable it temporarily and test the routes.
5. Cover the diagnostic step — inspect the response headers for `X-Matched-Path` and `X-Matched-Source`.
6. Include a `vercel.json` test that explicitly maps the dynamic route to rule out Vercel-level routing issues.
7. Note: this only affects Next.js projects with both a root `api/` directory and `pages/api/` routes.
