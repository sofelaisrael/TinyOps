**Context:** We use GitHub Actions to trigger Vercel deployments. If the build or deployment fails, we want an immediate notification in our `#ops` Slack channel so we can investigate without checking the GitHub tab.

**Goal:** Integrate a Slack notification step into an existing Vercel deployment workflow that only triggers on failure.

**Requirements:**
1. Use `slack-send` action or a simple `curl` to a webhook.
2. Include the PR title, the author, and a direct link to the Vercel build logs.
3. Use conditional `if: failure()` to ensure it doesn't fire on success.

**Output:** Provide the specific step configuration to be added to the deployment job.
