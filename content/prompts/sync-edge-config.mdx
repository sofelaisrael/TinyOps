**Context:** We use Vercel Edge Config for ultra-low latency feature flags and redirects. We want the "source of truth" to be a JSON file in our GitHub repository to allow for code reviews on configuration changes.

**Goal:** Write a GitHub Action that triggers on pushes to the `main` branch, reads `config.json`, and updates the specified Vercel Edge Config via the Vercel API.

**Requirements:**
1. Validate the JSON structure before syncing.
2. Use `curl` or a Node.js script to call the Vercel Edge Config Patch API.
3. Ensure the `TEAM_ID` is included for Pro/Enterprise teams.

**Output:** Provide the JSON structure example and the GitHub Action steps to sync it.
