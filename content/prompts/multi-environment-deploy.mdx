**Context:** We don't just have one production site. We need a stable staging environment that exactly mirrors production for final QA before we release to users.

**Goal:** Write a GitHub Action that uses branch logic to determine which Vercel Project ID to use for the deployment.

**Requirements:**
1. Use `if: github.ref == 'refs/heads/main'` style conditionals.
2. Use Vercel CLI with the `--prod` flag for production.
3. Pass different environment-specific variables (e.g., `STAGING_DB_URL`).

**Output:** Provide the conditional GitHub Action YAML for multi-environment support.
