**Context:** A React, Vue, or Svelte SPA deployed to Vercel works fine at the root `/` but returns a 404 when refreshing any client-side route like `/dashboard` or `/settings/profile`.

**Goal:** Configure `vercel.json` with the correct rewrite rules so all paths serve `index.html`, letting the client-side router handle navigation.

**Requirements:**
1. Write a `vercel.json` rewrite that maps all incoming requests to `/index.html`.
2. Ensure API routes under `/api/*` are NOT rewritten — they must still reach the serverless functions.
3. For Vite projects: include the explicit build config so Vercel detects the `dist` directory correctly.
4. Handle the case where both a static SPA and a serverless API coexist on the same domain.
5. Cover the `@vercel/static-build` build config with `distDir` for non-framework SPAs.
6. Include troubleshooting for blank white screens (missing JS/CSS due to incorrect `distDir`).
7. Note: some frameworks (Next.js, Nuxt) don't need this — only true SPAs using React Router, Vue Router, etc.

**Output:** Provide the `vercel.json` configuration for SPA routing, with variations for Vite, Create React App, and custom build tools.
