**Context:** My repository has a `docs/` folder, a `backend/` folder (Python), and a `frontend/` folder (Next.js). I deploy the frontend to Vercel.
**Goal:** I want to use Vercel's "Ignored Build Step" feature to prevent Vercel from building if changes were only made to the `docs/` or `backend/` folders.
**Requirements:**
1. Write a precise Bash script `ignore-build.sh`.
2. The script must use `git diff` to check if any files in the `frontend/` directory (or `package.json`) have changed in the latest commit.
3. If changes exist in `frontend/`, the script must exit with code `1` (telling Vercel to build).
4. If no changes exist in `frontend/`, it must exit with code `0` (telling Vercel to cancel the build).
**Output:** Provide the bash script and instructions on where to paste the execution command in the Vercel Dashboard settings.
