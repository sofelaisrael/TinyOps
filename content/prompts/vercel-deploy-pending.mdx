**Context:** Git pushes and deploy hooks return `{"state":"PENDING"}` but the deployment never progresses to the build phase. Manual redeploy from the Vercel dashboard works fine. This is often a build queue issue or cron job conflict on a Hobby plan.

**Goal:** Diagnose the cause of stuck PENDING deployments and unblock the queue either by clearing cron jobs or contacting Vercel support.

**Requirements:**
1. Explain why deployments get stuck in PENDING: build queue backlog, cron job conflicts on Hobby plan, or account-level issues.
2. Check for blocking cron jobs in the Vercel dashboard under Settings → Cron Jobs.
3. Use the Vercel CLI to cancel pending deployments: `vercel list` then `vercel rm <deployment-id>`.
4. Show how to use the Vercel API to cancel all pending deployments programmatically.
5. If no cron jobs or queue issues are found, provide the contact Vercel support path with relevant context.
6. Add a preventive measure: set a `timeout` on deployment hooks and add a retry mechanism.
7. Include a curl example that cancels stuck deployments via the Vercel API.

**Output:** Provide a diagnostic checklist and a cancel-stuck-deployments script.
