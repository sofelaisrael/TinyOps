**Context:** Deploying an Express.js backend to Vercel results in 404 on every route — even `/`. The build succeeds but nothing responds.

**Goal:** Configure the Express app as a Vercel serverless function with correct routing, including static file serving for SPAs if the frontend shares the same domain.

**Requirements:**
1. Export the Express app as a serverless function handler (required for Vercel).
2. Configure `vercel.json` with the correct `@vercel/node` build and `rewrites` to route API calls to the serverless function.
3. Serve API routes under `/api/*` and forward all other requests to index.html for a combined SPA + API setup.
4. Handle CORS headers properly in the serverless context.
5. Cover environment variables, especially database URLs and API keys that must be set in the Vercel Dashboard.
6. Note the limitations: 10s timeout on Hobby plan, cold starts, no persistent WebSocket connections.
7. Include an alternative using `@vercel/node` with a single entry point file.

**Output:** Provide the complete `api/index.js` entry point (with Express app export), `vercel.json` config, and notes on Vercel-specific limitations.
