**Context:** In a large project, developers often don't know who should review their PR. We want to automate this based on expertise (e.g., if CSS changes, ping the UI team).

**Goal:** Use a combination of a `CODEOWNERS` file and a GitHub Action to automatically assign reviewers.

**Requirements:**
1. Configure `.github/CODEOWNERS` for directory-level ownership.
2. Use an Action that respects these owners and adds them as reviewers when a PR is opened.
3. Handle "round-robin" assignment for larger teams.

**Output:** Provide a sample `CODEOWNERS` file and the Action to trigger assignment.
