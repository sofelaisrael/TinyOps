**Context:** Sometimes Vercel's build fails, but GitHub doesn't block the merge because the separate GitHub Action tests passed. We want Vercel's own status to be a "Required" check.

**Goal:** Configure the GitHub Repository and Vercel project to synchronize status checks so GitHub's branch protection rules can block merges if Vercel is unhappy.

**Requirements:**
1. Enable the Vercel GitHub Integration.
2. Identify the specific check names Vercel reports to GitHub (e.g., `Vercel`, `Preview`).
3. Set up a GitHub Action that waits/polls for these checks if they aren't appearing instantly.

**Output:** Provide the step-by-step configuration for GitHub Branch Protection and any glue Action needed.
