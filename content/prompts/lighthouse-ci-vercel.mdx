**Context:** We want to maintain high performance. Every pull request should be checked for Lighthouse scores before it's allowed to be merged.

**Goal:** Integrate Lighthouse CI into the GitHub Actions pipeline. It should wait for the Vercel preview URL to be ready, then run the audit.

**Requirements:**
1. Wait for Vercel deployment to finish using `amannn/action-vercel-deploy` or similar.
2. Run `@lhci/cli`.
3. Post a comment on the PR with the results.

**Output:** Provide the `.lighthouserc` config and the GitHub Action steps.
