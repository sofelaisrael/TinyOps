**Context:** We want to maintain a clean git history. Developers should name branches like `feat/abc` or `fix/123`.

**Goal:** Create a lightweight GitHub Action that runs on `pull_request` and regex checks the head branch name.

**Requirements:**
1. Use a simple bash script or a community action like `deepakputhraya/action-branch-name`.
2. Fail the build with a helpful message: "Your branch name must start with feat/, fix/, or chore/."

**Output:** Provide the YAML for the branch name check.
