**Context:** We want our final production deploy to Vercel to be as fast as possible. Since we already run builds in CI, we should share that cache with Vercel.

**Goal:** Configure Remote Caching in Turborepo so that the build artifacts generated during GitHub Actions are available to Vercel's build machines.

**Requirements:**
1. Set up Vercel Remote Caching in the Vercel Dashboard.
2. Inject `TURBO_TOKEN` and `TURBO_TEAM` into the GitHub Action environment.
3. Ensure the environment (Node version, OS) matches between GitHub and Vercel.

**Output:** Provide the environment variable setup and the `turbo build` command.
