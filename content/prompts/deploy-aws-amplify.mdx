**Context:** I have a Next.js 15 app and want to host it on AWS Amplify. I need a CI/CD pipeline that builds and deploys on every push to main.

**Goal:** Generate the `amplify.yml` configuration and the GitHub Action to trigger a manual deployment if needed.

**Requirements:**
1. Handle ISR and SSR correctly.
2. Cache `node_modules` and `.next/cache`.
3. Set up environment variables via the Amplify Console.

**Output:** Provide the `amplify.yml` file content.
