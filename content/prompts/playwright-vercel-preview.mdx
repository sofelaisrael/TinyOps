**Context:** I have a Next.js project using pnpm. I am deploying to Vercel.
**Goal:** Write a GitHub Actions `.yml` workflow that triggers on a pull request to the `main` branch.
**Requirements:**
1. Use `actions/setup-node` and cache pnpm dependencies globally to save build minutes.
2. Install Playwright browsers and run `pnpm test:e2e`.
3. *Crucial:* If and only if the tests pass, use the `vercel CLI` (with `VERCEL_ORG_ID` and `VERCEL_PROJECT_ID` secrets) to trigger a Preview Deployment.
4. Use a GitHub Action step to comment the resulting Vercel Preview URL directly on the PR.
5. Ensure I know exactly what settings to change in the Vercel Dashboard to disable automatic deployments so this action takes full control.
**Output:** Provide the complete YAML file and a step-by-step list of Vercel dashboard configurations needed.
